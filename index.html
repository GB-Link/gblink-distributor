GB-Link Distributor

Event distribution Pokémon over link cable using GB-Link USB adapter

Choose your Pokémon
Delivery mode

Your Game Boy Advance receives the Pokémon. Leave the game cartridge in the whole time.

  1. Save in a Pokémon Center.
  2. Leave at least one empty space in your party.
  3. Turn the Game Boy Advance off. Keep the cartridge inserted.
  4. Connect the adapter, then hold Start and Select while turning the Game Boy Advance back on.
  5. When the Pokémon’s sprite appears, it is already saved on that cartridge.
